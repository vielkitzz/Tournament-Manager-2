# Organização de pastas por arrasto

## Alterações
- Dividir cada pasta em três zonas durante o arrasto: topo para posicionar acima, centro para encaixar dentro e base para posicionar abaixo.
- Só permitir que uma pasta vire subpasta quando o cursor for solto na zona central claramente destacada.
- Aplicar o mesmo comportamento nas pastas de Times e Competições.
- Salvar a nova ordem para que ela permaneça após atualizar a página.
- Manter a proteção contra colocar uma pasta dentro dela mesma ou de suas subpastas.

## Validação
- Conferir ordenação para cima e para baixo entre pastas do mesmo nível.
- Conferir encaixe somente no centro e retorno à raiz fora das pastas.
- Executar verificação de compilação e testes relacionados.
